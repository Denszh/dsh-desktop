## 📦 我该下载哪个安装包？

不知道怎么选？按下面最简单的规则来：

| 你的电脑 | 下载这个文件 |
|---------|------------|
| **苹果 Mac（MacBook / iMac / Mac Studio）** | 文件里带 **`arm64`** 的那一个（`.dmg`） |
| **苹果 Mac（较旧的 Intel 芯片 Mac）** | 文件里带 **`x64`** 的那一个（`.dmg`） |
| **Windows 电脑** | 文件里带 **`x64`** 的那一个（`.exe`） |

> 💡 **最简单**：看文件名字里的 `arm64` 或 `x64` 字样。
> - 新买的 Mac / 苹果自家芯片 → `arm64`
> - Intel Mac 或 Windows → `x64`
>
> 不确定自己的电脑是哪种？打开「关于本机」（Mac）或「系统信息」（Windows），看芯片一栏写的是 Apple 还是 Intel。

> 📦 `.zip` 文件是给自动更新用的，**普通用户不需要下载**。
